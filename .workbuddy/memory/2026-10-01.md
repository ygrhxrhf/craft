## CloudBase PG TCP 直连调研（环境 aaa11-d1gfgozz987c564a5，个人版 baas_personal，ap-shanghai）

结论：个人版 + 共享集群（postgres-hypwq3vq, TenantType=SHARED）不支持任何形式的 TCP 直连。
- 官方社区答复（cnb.cool/tencent/cloud/cloudbase/community #1236/#1237/#1263）：个人版共享集群三条 TCP 路径全封：公网（安全组是独享能力）、云托管内网（VPC 是标准版+能力）、本地直连（无地址可填）。
- 价格文档（cloud.tencent.com/document/product/876/75213）：云托管「连接腾讯云 VPC」个人版为「-」。
- 官方 docs.cloudbase.net/database/postgresql/connecting-to-postgresql：连接信息「以控制台实际展示为准」——共享集群不展示。
- 官方支持的 TCP 通路 = 升级独享实例（docs.cloudbase.net/database/postgresql/database-management 有「升级为独享实例」控制台路径；社区反馈个人版该按钮可能无响应→工单）。
- 独享计费：按规格时长计 CU（1核2GiB=1CU/小时）+ 存储按分配容量时长计费（不可缩容）。个人版配额：15万CU/月、容量3GB/月、40,000资源点/月；超额：容量0.1元/GB/天、计算0.00011108元/CU。
- pg_roles 实证：平台组件各有独立角色（cloudbase_auth_admin_*/storage_admin_*/functions_admin_*/realtime_admin_*/authenticator/admin_*），与用户直连账号 cloudbase_postgres_postgres_hypwq3vq 隔离；重置用户账号密码不影响平台组件，但会影响 DMC/MCP SQL 通道（默认 role=cloudbase_postgres），重置后需验证。
- 云托管固定出口 IP 个人版支持（可把出口 IP 加进 PG 安全组走公网直连）。
