
## 第 100 批·上半（2026-09-30 00:3x–00:5x 本地＝UTC 16:3x–16:5x，**盘上样式批＝零浏览器调用、零写入**；★★★ **本目录第一次推翻自己的色阶结论**）

1. ★★★ **色阶是"两段式 18 档"，不是一段 alpha**＝`--red-*`／`--accent-blue-*` 各有 **18 档**（`-50…-900`，步长 50）：**`-50…-500`＝同一 RGB 的 alpha 阶**（`6｜12｜18｜24｜32｜40｜55｜70｜85｜100%`），**`-550…-900`＝不透明、逐档变暗的独立 RGB**（red `237 54 58`→`118 39 42`；accent-blue `44 103 217`→`34 60 111`，基色 `46 109 233`）。⇒ ⚠ **推翻第 97 批·尾记二的"强调色满值后缀是 `-500`、`-600`～`-900` 根本不存在"**（`gap.md` G971 与 `styles.md §九.2` 两处已就地 ✎，指向 G1009）；☆ 旧结论"`-950` 不存在"仍成立。⇒ **根因＝只扫到 alpha 段就收手** ⇒ 自检补一条＝**`new Set` 枚举手之后还要问"每段是不是同一种量纲"**（同一后缀在不同族／不同段里是两种东西：透明度 vs 明度）。
2. ★★★ **`[data-whatintent]` 是 CSS 契约级机制（349 处消费）⇒ 官方不用 `:focus-visible`**＝焦点环 `[data-whatintent=keyboard] .X:focus`、悬停 `[data-whatintent]:not([data-whatintent=touch]) .X:hover` ⇒ "触屏无 hover"是**运行时判定**不是 `@media (hover:hover)`；☆ 与第 94 批静态读到的 `Npe` 触觉（`dataset.whatintent==="touch"` → `navigator.vibrate`）是**同一属性的两个消费者**，**写入点仍未定位**。⇒ 本地用 Tailwind `focus-visible:`（`src/components/ui/button.tsx:6`）＝**有意偏差、不要求改**；但本地**没有**触屏无 hover 的等价机制（要嘛自建属性、要嘛 `@media (hover:hover)` 并注明）。
